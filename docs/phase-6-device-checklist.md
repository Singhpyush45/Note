## Look and appearance
- [ ] Settings › Appearance: change accent, glass, blur, corner radius, density → the app changes at once.
- [ ] Wallpaper: pick a preset, then a photo from the gallery → shows behind home and settings; text stays readable.
- [ ] Android 12+: scroll the notes under the header → the header blurs what's behind it.
- [ ] Dark theme: everything readable; Reset appearance brings the default look back.

## Home
- [ ] Tap + → four choices appear; tap + again (×), tap outside, press Back → each closes it.
- [ ] Import file: a PDF → PDF note; a .txt → text note; a photo → new note with the photo.
- [ ] Card ⋮ → Rename works; Duplicate makes a copy.
- [ ] Long-press a card → selection bar; tap two more → "3 selected"; Archive → all three archived (Undo works).
- [ ] Chips: Favourites and a notebook filter the list.

## Templates
- [ ] + › Choose template → separate screen with Basic, Academic, Planners, Journals, Creative, Custom.
- [ ] Tap a chip → jumps to that section. Search "budget" → only Monthly budget.
- [ ] Tap Weekly planner → big preview → Use template → you can write in the Monday box. Back → home.
- [ ] In that note, ⋮ › Add page → the new page is also a weekly planner.
- [ ] Basic › Custom → make "My grid" (Grid, Title & date, cream paper) → Save → it's under Custom; use it.
- [ ] Custom template preview: Edit, Rename, Duplicate, Delete all work. Deleting it doesn't change the note.
- [ ] A built-in → Customise → change page size to A4 wide → Save; the built-in itself is unchanged.
- [ ] Settings › Templates opens the same screen at Custom.

## Page settings (handwriting note ⋮ › Page settings)
- [ ] Infinite scroll: the pages join with no gap; writing on the last page adds a new page below.
- [ ] Horizontal: pages go side by side; swipe left/right moves between pages; "page x / y" follows.
- [ ] Page size A4 wide and Long: all pages change; writing near the old bottom edge is still visible.
- [ ] Style Grid + Wide on "All pages", then Dot on "This page" only.
- [ ] Paper colour from Warm, then a Custom colour → pages change; text and lines stay readable.
- [ ] Dark theme: pages show as dark paper, black ink light, blue ink blue; turning "Dark paper" off shows white
      paper again. A stroke looks the same while drawing and after lifting the pen.
- [ ] ⋮ › Export as PDF → open the file in another app: same page sizes, paper colour, template and ink.
- [ ] ⋮ › Share as PDF → WhatsApp/Gmail receives it.
- [ ] A PDF note: Page settings shows layout/direction only.

## Note defaults (Settings)
- [ ] "Blank note opens as Handwriting" + Dot + A4 wide + Infinite → + › Blank note opens that kind of page.
- [ ] Back to Typed → Blank note opens the text editor again.
- [ ] Rotate the phone and force-stop/reopen the app in a note with page settings → they're kept.
