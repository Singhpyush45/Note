# Phase 7 — device checklist (pens, pencils, brushes, colours, laser)

To be done by a person on a real phone and, if possible, a tablet with a stylus. Mark each line ✅ / ❌ with a note.
CI can't check feel, latency, or how textures look on a real screen.

## Tool bar and panel
- [ ] Tool bar shows Pen, Marker, Pencil, Brush, Highlighter, Eraser, Lasso, Laser; each drawing tool has a small
      colour bar under it showing its current colour.
- [ ] Tapping the chosen tool again (or the variant name, e.g. "Ballpoint ▴") opens the options panel; × closes it.
- [ ] Opening the panel doesn't move or resize the page; touches on the panel never draw on the page.
- [ ] Every variant tile shows a preview in the current colour; tapping one selects it and the next stroke uses it.
- [ ] Size and opacity sliders change the next stroke; the highlighter can't go above 70 % opacity.
- [ ] Pressure switch: with a stylus, pressing harder makes pressure variants thicker; switched off, the line is even.
- [ ] "Recently used" shows the last set-ups; tapping one switches tool, variant, colour and size.
- [ ] Settings survive closing the note and restarting the app.

## Variants (owner brief §12) — draw each, slowly and fast
- [ ] Pens: ballpoint, fine, gel, fountain (thick/thin with direction), fineliner, technical (even), dot pen (dots).
- [ ] Markers: felt, chisel. Highlighters: chisel, round, fine — stay under the writing.
- [ ] Pencils: natural, HB, 2B, 4B (darker/softer), mechanical (fine, even), sketch, graphite — grain visible.
- [ ] Brushes: basic, soft, calligraphy brush/pen, airbrush (soft spray), oil (bristle streaks), watercolour (soft
      wash with a darker edge), crayon, chalk, charcoal, texture, artistic (tapered), marker brush.
- [ ] Live stroke looks the same as the finished one; note the latency compared with the ballpoint.
- [ ] Undo/redo, eraser, lasso move/resize/recolour work on variant strokes.
- [ ] Thumbnails on the home screen and PDF export show the variants.
- [ ] Dark theme with dark paper: variants readable.

## Colours (owner brief §14)
- [ ] Palette button opens the colour picker; palettes Basic, Greys, Pastel, Deep, Neon.
- [ ] Custom: drag on the square, hue bar, HEX field (#RGB and #RRGGBB, invalid input shown), red/green/blue.
- [ ] Save adds to "My colours"; long-press removes one. Recent colours appear in the picker and the tool bar.
- [ ] Changing colour keeps the tool's opacity.

## Laser pointer (owner brief §17)
- [ ] Laser draws a glowing trail that fades within about a second; nothing is added to the note (undo stays off).
- [ ] Styles Solid, Neon, Dot; RGB rainbow flows along the trail; single colours; three widths.
- [ ] With "fingers scroll" on, a finger scrolls and the stylus points; two fingers still zoom.
- [ ] Stylus eraser end still erases while the laser is chosen.
- [ ] Smooth (no stutter) on the device; check battery/heat after a few minutes of pointing.
