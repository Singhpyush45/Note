# Phase 5 — device checklist (attachments, scanner/OCR, audio, reminders)

Install `APP_NAME-test.apk` from the `test-build` release. Mark each line ✓ or ✗ (with what happened).
Device: ________  Android version: ________

## Attachments
- [ ] Note → 📎 → Photos: pick 3 photos → previews appear under the title, upright (try a portrait photo).
- [ ] 📎 → Camera: take a photo → it's attached. Rotate the phone while the camera is open → still attached.
- [ ] 📎 → Files: attach a PDF and a .zip → PDF shows page 1, zip shows name · size.
- [ ] Tap a photo → full-screen viewer, pinch-zoom works. Back closes it.
- [ ] ⋮ on an attachment → Share → WhatsApp/Gmail receives the file.
- [ ] Remove an attachment → Undo puts it back in the same place.
- [ ] Gallery → Share a photo → APP_NAME → a new note opens with it.
- [ ] Library card shows the first photo and the attachment count.

## Scanner and search
- [ ] 📎 → Scan document → scan 2 pages of a printed page → attached as a PDF.
- [ ] Wait ~1 minute, search a word from the scanned page → the note is found ("Page 1" / "In …").
- [ ] Search a word from a photo of a printed sign → found.
- [ ] Settings → Privacy → turn "Find text in photos and PDFs" off → that search no longer finds it.

## Audio
- [ ] 📎 → Record audio → allow microphone → red bar with a running time; notification "Recording".
- [ ] Tap "Add marker" twice while speaking → timestamps appear in the text.
- [ ] Stop → a player appears; play, pause, drag the seek bar.
- [ ] Tap a marker chip → playback starts from that time.
- [ ] Refuse the microphone permission (fresh install) → message, the rest of the app works.
- [ ] Start recording, swipe the app away from recents → reopen → the recording is attached.

## Reminders
- [ ] Note ⋮ → Remind me → "Later today" (or pick a time 2 minutes ahead) → Save → chip under the title.
- [ ] Lock the phone → the notification arrives on time with the note title; tap → the note opens.
- [ ] Snooze 10 min on a notification → it comes back 10 minutes later.
- [ ] Checklist item → toolbar alarm button → reminder for the task → notification shows the task text.
- [ ] Tick that task before the time → no notification for it.
- [ ] Repeat "Every day" → after it rings, the chip shows tomorrow.
- [ ] Restart the phone with a reminder pending → it still rings.
- [ ] Settings → Apps → APP_NAME → Notifications off → the note shows "Notifications are off… Turn on".
- [ ] Handwritten note ⋮ → Remind me → alarm button appears in the top bar.
- [ ] Library card shows the next reminder time.

## Audio extras and voice typing
- [ ] 📎 → Audio file → pick an MP3/M4A from your phone → a player with its length appears.
- [ ] Tap the speed button (1× → 1.25× → 1.5×…) while playing → speed changes.
- [ ] ⋮ on an attachment → Rename → new name shows.
- [ ] Toolbar 🎤 → English (India) → read the line about where speech is processed → Start → allow microphone.
- [ ] Speak two sentences → words appear while you speak; Pause, Resume, Stop, edit a word, Insert → the text
      is in the note at the cursor; Undo removes it.
- [ ] Turn on airplane mode and try again → either it works on the phone, or a clear "no internet" message.
